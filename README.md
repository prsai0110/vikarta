# VIKARTA — Creative Advertising & Brand Studio

Premium React/Vite agency website rebuilt with a classic editorial creative-studio direction.

## Run

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Included

- React + Vite
- Framer Motion animation system
- Cinematic page loader
- Scroll progress
- Hero reveal/parallax treatment
- Responsive animated navigation
- Interactive services selector
- Infinite creative-discipline marquee
- Scroll-reveal process section
- Interactive work/case-study modal
- Premium final CTA
- Contact form UI with validation
- Responsive desktop/tablet/mobile layouts
- Reduced-motion support
- No fake client logos, testimonials, awards, or statistics

Real phone/email/website/social details are intentionally left as placeholders until Vikarta provides them.
